# 🏔️ Project: Local Blog UI System (Markdown → Beautiful Website)

## 🎯 Goal
Build a complete local blogging system that:

- Reads blog content from Task.md or /blogs folder
- Converts it into a beautiful UI website
- Runs locally in browser
- Ready for GitHub Pages deployment

---

# 🧩 Core Features

## 1. Frontend UI (Must Build)

Create a modern blog UI with:

- Homepage showing blog list
- Single blog page view
- Clean Pinterest-style layout
- Responsive design (mobile + desktop)
- Card-based blog preview
- Smooth typography and spacing

Use:
- HTML
- CSS
- Vanilla JavaScript (no frameworks)

---

## 2. Markdown Support System

System must convert:

- # Headings
- ## Subheadings
- ### Sub-subheadings
- Paragraphs
- Bullet points
- Images ![alt](path)

into clean HTML automatically.

---

## 3. Folder Structure

Create this structure:
BlogSystem/
├── index.html
├── post.html
├── /blogs
│ └── blog1.md
├── /images
├── /css
│ └── style.css
├── /js
│ └── app.js

---

## 4. Blog Engine (Important)

Create JS logic that:

- Reads markdown files from /blogs
- Converts markdown to HTML
- Dynamically renders blog posts
- Supports multiple blog posts

---

## 5. Image System

- Load images from /images folder
- Support responsive images
- Auto fallback if image missing

---

## 6. UI Design Style

Design must be:

- Clean and minimal
- Pinterest-style aesthetic
- White background + soft shadows
- Large readable fonts
- Mobile friendly

---

## 7. Homepage Features

Homepage must include:

- Blog cards (title + preview + image)
- Click to open full blog
- Simple navigation bar

---

## 8. SEO Features

Add:

- Meta title + description
- Open Graph tags
- Clean HTML structure
- Fast loading

---

## 9. Output Requirement

Final system must:

✔ Run locally by double click (index.html)  
✔ Work without backend  
✔ Open in browser perfectly  
✔ Be ready for GitHub Pages hosting  

---

## 🚀 Bonus Features (Optional)

- Dark mode toggle
- Search blogs
- Category filter
- Tags system
